# Scenes

These scenes are created in-Editor on first project open. See `docs/07_Setup_Instructions.md`.

Required scenes for Mission 1 vertical slice:

| Scene | Purpose |
|---|---|
| `00_Bootstrap.unity` | Holds the persistent Bootstrap prefab; first scene in Build Settings |
| `01_MainMenu.unity` | Title screen |
| `02_Hub_PlayerShip.unity` | Player ship interior; mission select console |
| `Mission01_Kestrel.unity` | The vertical slice |

Add scenes to Build Settings in that order.
